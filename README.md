# Калькулятор размещения облигаций

Калькулятор помогает банку определить объём участия в выпуске облигаций и распределить его между четырьмя каналами: размещением институциональным инвесторам, размещением рознице, покупкой на баланс для перепродажи и удержанием до погашения.

Задача — максимизировать чистую прибыль за весь срок сделки с учётом спроса, балансового лимита, стоимости фондирования, ожидаемых потерь, капитала, налогов и порогов IRR/ROE. Исходные данные четырёх сделок вымышленные и доступны для редактирования.

## Возможности

- Выбор сделки и изменение её условий, траектории ключевой ставки, общих коэффициентов и порогов доходности.
- Сценарии первичного спроса ниже/выше объёма выпуска с сохранением пропорций институционалов и розницы.
- Быстрый поиск **MILP** с проверкой максимума и глубокий поиск **Differential Evolution** с несколькими запусками.
- Распределение по каналам, чистая прибыль, годовые IRR/ROE, статус поиска и уточнения.
- Графики, помесячный план продаж и погашения, подробные начисления и выгрузка Excel.
- Объяснение достигнутых ограничений и проверка добавления одного шага в каждый канал. Сравнение влияния отдельного увеличения розничного спроса, темпа перепродажи и балансового лимита на 10% с повторной оптимизацией MILP. При нулевом параметре добавляется один шаг; вывод о лучшем изменении делается только при подтверждённых максимумах всех сравниваемых вариантов. Эти проверки добавляют время к основному расчёту, до 5 с на каждый MILP-вызов плюс подготовка. Для DE дополнительно рассчитывается сопоставимая база MILP. Детали включены в Excel.

Проценты на странице округляются до двух знаков после запятой. Проверка порогов и Excel используют исходные значения без округления. Суммы ввода — млн ₽, ставки — проценты; внутри модели деньги хранятся в рублях, ставки — долями единицы.

## Быстрый запуск

Нужен **Python 3.10 или новее; рекомендуется Python 3.12**, на котором проверена работа приложения. Для первого запуска требуется интернет. Скачайте проект через **Code → Download ZIP** и полностью распакуйте архив либо клонируйте репозиторий:

```text
git clone https://github.com/DomiStjls/bond-placement-calculator.git
cd bond-placement-calculator
```

Для приватного репозитория нужен доступ к нему в GitHub.

### Windows

1. Установите Python, отметив **Add python.exe to PATH**.
2. В распакованной папке дважды нажмите **start_calculator.cmd**.

Либо запустите из PowerShell/терминала в папке проекта:

```powershell
py -3 run_calculator.py
```

Если команда `py` недоступна, используйте `python run_calculator.py`.

### macOS

Установите Python 3.12 и выполните в Terminal из папки проекта:

```bash
python3 run_calculator.py
```

### Linux

Установите Python с поддержкой `venv` и `pip`. Например, для Ubuntu/Debian:

```bash
sudo apt update
sudo apt install python3 python3-venv python3-pip
```

Затем из папки проекта:

```bash
python3 run_calculator.py
```

Скрипт сам создаёт изолированное окружение `.venv`, устанавливает зависимости и запускает калькулятор. При повторном запуске установка пропускается, если `requirements.txt` не изменился. Исходные данные проекта не перезаписываются.

Откройте в браузере **Local URL** из терминала, обычно **http://localhost:8501**. Держите окно запуска открытым; **Ctrl+C** останавливает приложение. Адрес localhost доступен на компьютере, где запущена программа.

Выберите сделку → настройте параметры → нажмите **«Рассчитать · MILP»** или **«Глубокий поиск · DE»** → изучите отчёт и при необходимости скачайте Excel.

## Как работать с проектом

1. **Выберите исходную сделку.** Её условия заполнят форму. Можно изменить название, рейтинг и финансовые параметры. Рейтинг сам по себе не меняет PD или риск-вес — они задаются отдельно.
2. **Укажите условия расчёта.** Суммы вводятся в млн ₽, ставки — в процентах. В дополнительных настройках доступны КС, налоги, комиссии, пороги, шаг распределения и время поиска.
3. **Рассчитайте базовый вариант.** Начните с MILP. DE можно использовать для дополнительного поиска. По окончании проверьте статус: найденный допустимый вариант и подтверждённый максимум — разные результаты.
4. **Изучите распределение и объяснения.** Первые два канала — покупки инвесторов; последние два — собственный баланс банка. Блок объяснений показывает ограничения и результат изменения спроса, темпа продаж или лимита.
5. **Сравните условия.** Для большего запаса доходности повысьте пороги ROE/IRR и пересчитайте. Для другого спроса выберите сценарий: он задаётся относительно объёма выпуска. При изменении формы старый результат помечается как устаревший.
6. **Сохраните результат.** Excel содержит распределение, месячный план, начисления по каналам, сравнение условий и параметры. Это снимок расчёта: изменение Excel не запускает оптимизацию. Скачайте файл до перезапуска приложения — история расчётов между запусками не сохраняется.

Для изменения стартовых условий отредактируйте `data/deals.json` и `data/system.json`. В этих файлах суммы указаны в рублях, ставки — долями единицы: `0.14` означает 14%. Пользовательские изменения в форме эти файлы не перезаписывают.

Если меняете код, расчёты находятся в `bond_calculator/`, интерфейс — в `app.py`, установка и запуск — в `run_calculator.py`. После изменений финансовой логики запустите тесты из раздела ниже. Материалы проекта: [отчёт о работе](WORK_REPORT.md), [идеи развития с ИИ](AI_DEVELOPMENT.md), [методика и допущения](MODEL_ASSUMPTIONS.md).

## Ручная установка

Если хотите самостоятельно управлять окружением:

**Windows / PowerShell:**

```powershell
py -3 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m streamlit run app.py
```

**macOS / Linux:**

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python -m streamlit run app.py
```

Активация окружения не требуется. Если порт занят, остановите предыдущий запуск или добавьте к команде Streamlit `--server.port 8503`.

При ошибке установки проверьте версию Python, доступ к интернету и право записи в папку проекта. В корпоративной сети установка пакетов может требовать настройки прокси или помощи администратора. Холодный и повторный запуск проверены в отдельной чистой папке на Windows / Python 3.12; macOS и Linux отдельно не тестировались.

## Методы и ограничения

**MILP** решает целочисленные задачи на линейных участках перепродажи. Кандидат пересчитывается финансовым ядром; максимум подтверждается только при достижении общей верхней границы в численных допусках. При незавершённом поиске возвращается соответствующий статус.

**DE** улучшает популяцию распределений, выполняет несколько запусков и локальную доводку. Итог проходит проверку финансовым ядром. Метод не доказывает глобальную оптимальность; отсутствие найденного ответа не доказывает отсутствие допустимого решения.

По умолчанию шаг распределения — 1 млн ₽, пороги — IRR ≥30% и ROE ≥26,5%. Прибыльный вариант без капитала допускается с неприменимыми IRR/ROE. Потоки с несколькими сменами знака не получают автоматического допуска по IRR. Лимиты времени мягкие: финальная проверка может увеличить длительность расчёта.

При равной прибыли выбирается меньший занятый капитал за срок: сумма месячного капитала /12, в ₽·годах. MILP выполняет второй проход с сохранением максимальной прибыли; результат отдельно содержит `capital_optimality_proven`. Если времени не хватило или проверка кандидата не пройдена, подтверждение максимума прибыли сохраняется, а минимум капитала не объявляется доказанным. В DE правило действует среди найденных кандидатов и при локальной доводке, без глобального доказательства. Равенство прибыли определяется только с вычислительным допуском max(0,000001 ₽, |прибыль| ×1e−12), без округления отображения.

Срок в интерфейсе ограничен 600 месяцами. Отрицательные ставки/спреды и капитал больше позиции не поддерживаются. Отдельный вариант с запасом по доходности пока не реализован.

Excel — снимок результата и настроек, а не книга формул для повторной оптимизации. Приложение запускается локально; размещённая веб-версия не публиковалась.
